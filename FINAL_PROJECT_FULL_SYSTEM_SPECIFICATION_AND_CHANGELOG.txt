1. EXECUTIVE PROJECT OVERVIEW & ARCHITECTURE
================================================================================
Smart Community is a full-stack, enterprise-grade educational, skill exchange, and 
career development web platform designed for Cambodian students, mentors, and recruiters.

TECH STACK ARCHITECTURE:
* Frontend:
  - Framework: React 19 with Vite 8 (Ultra-fast build and HMR).
  - Routing: React Router 7 with role-protected route guards.
  - State Management: React Context API (GlobleContext, LanguageContext, ThemeContext).
  - Styling: Pure CSS3 Design System with CSS Tokens, Glassmorphism, and 100% Dark Mode.
  - Icons: React Icons (Feather Icons `react-icons/fi`, Ionicons `react-icons/io5`).
  - Realtime: Socket.IO Client 4.8.
  - Push Notifications: Firebase Cloud Messaging (FCM) web push service worker.
  - Document & PDF Generation: Custom CSS Print Stylesheet with pixel-perfect A4 pagination.

* Backend:
  - Runtime: Node.js (v20+ / v24+).
  - Framework: Express.js with Helmet security headers, CORS origin whitelisting, and gzip compression.
  - Database: MySQL 8 (mysql2 with connection pool, prepared statements, and transactional safety).
  - Realtime Engine: Socket.IO 4.8 with authenticated user rooms (`user:${id}`) and conversation rooms (`conversation:${id}`).
  - Authentication: JSON Web Tokens (JWT) signed with HMAC-SHA256, Bcrypt password hashing (12 salt rounds), legacy PBKDF2 backward compatibility.
  - Email Engine: Nodemailer SMTP with HTML templates for email verification and password resets.
  - Push Delivery: Firebase Admin SDK with background device token dispatch.

3. BACKEND ARCHITECTURE & COMPLETE REST API ENDPOINTS
================================================================================

All endpoints are hosted under `/api` and secured with JWT Bearer authentication.

1. AUTHENTICATION & USER MANAGEMENT (`/api/auth`):
   - POST `/auth/register` (Register student, mentor, or recruiter)
   - POST `/auth/login` (Authenticate and issue JWT)
   - POST `/auth/forgot-password` (Generate password reset token & send email)
   - POST `/auth/reset-password` (Reset password with token)
   - GET  `/auth/verify-email` (Confirm email address)
   - GET  `/auth/me` (Fetch current logged-in user profile)
   - PATCH `/auth/me` (Update user details, bio, avatar, skills)

2. NOTIFICATIONS & PREFERENCES (`/api/notifications`):
   - GET    `/notifications/unread-count` (Fast, un-cached unread count for Navbar)
   - GET    `/notifications` (Paginated notification list with type & unread filters)
   - PATCH  `/notifications/:id/read` (Mark single notification as read)
   - PATCH  `/notifications/read-all` (Mark all notifications or category as read)
   - DELETE `/notifications/:id` (Delete single notification)
   - DELETE `/notifications/read` (Clear all read notifications)
   - GET    `/notification-preferences` (Fetch user alert settings & push status)
   - PATCH  `/notification-preferences` (Update channel preferences)
   - POST   `/notification-push-token` (Register Firebase FCM token)
   - DELETE `/notification-push-token` (Unregister Firebase FCM token)

3. COURSES & LESSONS (`/api/courses`):
   - GET `/courses` (List all courses with category & level filters)
   - GET `/courses/:slug` (Get course detail by slug)
   - GET `/courses/:slug/lessons/:lessonId` (Get lesson details & video ID)
   - POST `/courses/:id/enroll` (Enroll in course)
   - PATCH `/courses/:id/lessons/:lessonId/complete` (Mark lesson completed)

4. SKILL EXCHANGE & MATCHMAKING (`/api/skill-exchanges`):
   - GET   `/skill-exchanges` (List open exchange proposals)
   - POST  `/skill-exchanges` (Create new skill exchange proposal)
   - GET   `/skill-exchanges/:id` (Get exchange details & chat metadata)
   - PATCH `/skill-exchanges/:id/status` (Update status: accept, decline, in_progress)
   - POST  `/skill-exchanges/:id/request-completion` (Request mutual completion)
   - POST  `/skill-exchanges/:id/confirm-completion` (Confirm mutual completion)

5. MENTORSHIP & SESSIONS (`/api/mentors`, `/api/sessions`):
   - GET  `/mentors` (List verified mentors with skill & price filters)
   - GET  `/mentors/:id` (Get mentor profile, availability & reviews)
   - POST `/mentors/:id/book` (Book mentoring time slot)
   - POST `/mentors/apply` (Submit mentor application)
   - GET  `/sessions` (List upcoming live sessions)
   - POST `/sessions` (Create live learning session)
   - POST `/sessions/:id/register` (Register for session)

6. JOBS & RECRUITER ATS (`/api/internships`, `/api/applications`):
   - GET   `/internships` (List internships with search & tags)
   - POST  `/internships` (Recruiter post new job)
   - GET   `/internships/:id` (Get job detail)
   - POST  `/internships/:id/apply` (Submit student application with CV)
   - GET   `/recruiter/applications` (Fetch applicants for recruiter ATS)
   - PATCH `/internship-applications/:id/status` (Update candidate hiring stage)
   - GET   `/my-applications` (Student fetch their application statuses)

7. COMMUNITY FORUM (`/api/forum`):
   - GET   `/forum/posts` (List questions with category & sort filters)
   - POST  `/forum/posts` (Create new question)
   - GET   `/forum/posts/:id` (Get thread details and answers)
   - POST  `/forum/posts/:id/answers` (Submit answer)
   - PATCH `/forum/answers/:id/accept` (Mark verified accepted answer)
   - POST  `/forum/posts/:id/vote` (Upvote/downvote post)

8. REALTIME MESSAGING (`/api/messages`, `/api/conversations`):
   - GET  `/conversations` (List user conversations with unread counts)
   - GET  `/conversations/:id/messages` (Get paginated chat messages)
   - POST `/conversations/:id/messages` (Send text message or file attachment)
   - POST `/conversations` (Start new 1-on-1 conversation)
