## SECTION 02: System Architecture & Security

### Slide 05 — High-Level Full-Stack Architecture
- **Client Tier:** React 19 + Vite (`frontend_user` & `frontend_admin`), responsive design system, mobile bottom tab bar.
- **Application Tier:** Node.js (v22+) + Express REST API, JWT auth guard, Socket.IO real-time engine.
- **Data & Integration Tier:** MySQL 8.4 (`final_pro`) relational database, Bakong KHQR payment gateway, Jitsi Meet WebRTC conferencing.

> **Speaker Notes (Khmer):**  
> ស្ថាបត្យកម្ម Full-Stack របស់យើងបែងចែកជា ៣ ជាន់ច្បាស់លាស់៖ Client Tier បង្កើតដោយ React 19 និង Vite ដែលមានទំហំស្រាល និងល្បឿនលឿន។ Application Tier គឺ Express REST API និង Socket.IO សម្រាប់ Real-Time Messaging។ និង Data Tier គឺទិន្នន័យ MySQL `final_pro` ភ្ជាប់ជាមួយសេវាទូទាត់ប្រាក់ Bakong KHQR និង Jitsi Meet។

### Slide 06 — Database Schema & Relational Integrity (`final_pro`)
- Strongly-typed relational schema preserving referential integrity via foreign keys and ACID transactions.
- Tables: `users`, `user_skills`, `courses`, `course_payments` (KHQR), `skill_exchanges`, `mentorship_bookings`, `internships`, `companies`, `conversations`, `messages`.

> **Speaker Notes (Khmer):**  
> ចំពោះមូលដ្ឋានទិន្នន័យ យើងជ្រើសរើសយក MySQL 8.4 ដោយសារប្រព័ន្ធរបស់យើងមានទិន្នន័យដែលមានទំនាក់ទំនងជិតស្និទ្ធ (Relational Data)។ MySQL ធានាថាប្រតិបត្តិការទូទាត់ប្រាក់ ការចុះឈ្មោះរៀន និងការដោះដូរជំនាញ មិនមានទិន្នន័យស្ទួន ឬបាត់បង់ (Data Consistency)។

---

### Slide 07 — Security, Authentication & Role Authorization
- **Password Hashing:** `bcrypt.hash(password, 10)` prevents plain-text exposure.
- **Stateless Tokens:** 24h JSON Web Tokens (JWT) passing user identity and role.
- **Object-Level Authorization:** Verified in automated security tests (10/10 PASS). Recruiter A cannot alter Recruiter B's applications; students cannot accept unauthorized swaps.
- **Server-Side Pricing & KHQR:** Dynamic MD5 transaction verification prevents price tampering.

> **Speaker Notes (Khmer):**  
> ប្រព័ន្ធសុវត្ថិភាពត្រូវបានធ្វើតេស្តជាប់ 100% (10/10 automated tests)៖ យើងប្រើ `bcrypt` សម្រាប់ Password, ប្រើ JWT ជាមួយ Role-Based Access Control, និងមាន Object-Level Authorization ការពារកុំឱ្យក្រុមហ៊ុនមួយលួចមើលបេក្ខជនរបស់ក្រុមហ៊ុនមួយទៀត។
